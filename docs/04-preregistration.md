# 사전 분석 계획 (Preregistration)

- 작성일: 2026-10-30, **데이터 수집 전**
- 고정 증거: 이 파일과 `analysis/run_analysis.py`가 처음 커밋된 시점의 Git 기록. 수집 시작 후 이 파일을 고치면 Git 이력에 남고, 고친 이유를 `03-design.md` 설계 변경 기록에 적는다.
- 이 계획을 미리 고정하는 이유: 데이터를 본 뒤 제외 기준이나 검정 방법을 고르면 "결과를 맞추려 고친 것"과 구별할 수 없다.

## 1. 가설

목표 자극 500ms 전 테두리 시각 경고 신호가 있으면, 없을 때보다 같은 참가자의 단순 반응시간이 짧아진다.

## 2. 수집 규칙

- 기간: 링크 첫 공유일 D0부터 D0+6일 23:59(KST)까지.
- 수집 중에는 분석 스크립트를 실제 데이터에 돌리지 않는다. 확인하는 것은 저장 건수뿐이다.
- 기간 종료 시점까지 완료한 세션 전원을 분석 대상 후보로 한다.

## 3. 제외 규칙

**참가자 단위 (순서대로 적용)**

1. 같은 브라우저의 두 번째 이후 참여(`repeat_participation = true`) → 제외
2. 본 시행 40행을 모두 남기지 않은 세션 → 제외
3. 아래 시행 제외 후 유효 시행이 30개 미만(제외율 25% 초과)이거나, 어느 한 조건의 유효 시행이 10개 미만 → 제외

**시행 단위**

- 연습 시행 전부
- 목표 자극 전에 누른 조기 반응(`anticipation`)
- 1500ms 안에 반응하지 않은 놓침(`timeout`)
- 시행 도중 탭·앱 전환이 감지된 시행(`hidden_during_trial = true`)
- 반응시간 100ms 미만 (자극을 보고 낸 반응으로 보기 어려움)

## 4. 종속변수

참가자별·조건별 유효 반응시간의 **중앙값**. 분석 단위는 참가자별 차이 `d = 중앙값(신호 있음) − 중앙값(신호 없음)`. 음수면 신호가 있을 때 빠르다.

중앙값을 쓰는 이유: 반응시간 분포는 오른쪽 꼬리가 길어 평균이 소수의 느린 반응에 끌려간다. 중앙값은 이상값과 절단 기준의 영향을 덜 받는다(Ratcliff, 1993).

## 5. 확증 분석과 판정 규칙

- **주 검정**: `d`에 대한 단측 Wilcoxon 부호순위 검정(대립가설: 중앙값 < 0), α = .05
- **판정**: p < .05 이고 `d`의 중앙값 < 0 이면 "가설이 지지되었다". 그 외에는 "지지되지 않았다".
- p ≥ .05는 "효과가 없다"가 아니라 "이 표본으로는 효과를 확인하지 못했다"로 해석한다.

## 6. 보조 분석 (함께 보고)

- 단측 대응 t검정(참가자별 중앙값), 효과크기 dz, 평균 차이의 95% 신뢰구간
- `d` 중앙값의 부트스트랩 95% 신뢰구간 (재표집 10,000회, 시드 20261030)
- 부호 검정: 신호가 있을 때 더 빠른 참가자 수
- 민감도 분석: 실제 분석 인원에서 검정력 .80으로 잡아낼 수 있는 최소 dz

## 7. 탐색 분석 (확증이 아님을 논문에 명시)

- 입력 방식(터치/마우스/키보드)별 `d`
- 조건별 조기 반응 건수: 신호가 오히려 성급한 반응을 부르는지

## 8. 계획 밖의 분석

데이터를 본 뒤 떠오른 분석은 할 수 있지만, 논문에 "사전 계획에 없던 분석"으로 따로 표시하고 확증 결론에 쓰지 않는다.
