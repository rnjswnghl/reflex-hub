## 3줄

1. **AI에게 맡긴 일** — 가설 문장의 결함 찾기, 실험 페이지·수집 API·분석 코드 작성, 문헌 후보 제시와 서지 대조, 논문 원고 초안. 
2. **내가 판단한 일** — 다른 AI가 제안한 게임 5개 가운데 스트룹 과제 대신, 직접 만든 웹 페이지로 사람들의 반응 데이터를 모으는 "시각 효과·경고 유무" 실험을 주제로 골랐다. AI가 만든 4분짜리 실험을 직접 해 보고, 짧은 미니게임 여러 개와 순위표 형식으로 바꾸게 했고, 대기 점이 목표 원과 헷갈린다는 결함을 찾았다. (결정 대기: 데이터를 본 뒤 해석에서 내가 내린 판단을 한 문장 추가)
3. **AI의 판단을 확인하거나 뒤집은 일** — AI가 거절한 '중도 이탈률 수집'을 다시 넣게 했다. (결정 대기: `docs/review/2026-10-30-review.md`의 처리안 가운데 내가 받아들이거나 바꾼 것과 그 이유. 특히 거절 2건)
