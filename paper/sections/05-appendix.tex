\section{재현 방법}\label{app:repro}
재현 패키지(ZIP)를 풀거나 \url{https://github.com/rnjswnghl/reflex-hub}를 받은 뒤 아래를 실행하면, 원자료에서 이 논문의 모든 수치와 그림이 다시 만들어진다.
자세한 내용은 패키지의 \texttt{REPRODUCE.md}에 있다.

\begin{enumerate}
\item 환경: Python 3.10 이상, \texttt{pip install -r analysis/requirements.txt}(버전 고정). 논문 빌드에는 XeLaTeX이 필요하다.
\item 원자료 정리: \texttt{python3 analysis/build\_dataset.py}\\
\texttt{data/raw/sessions/**/*.json} $\to$ \texttt{data/raw/trials.csv}, \texttt{rounds.csv}, \texttt{funnel.csv}
\item 사전 등록한 분석: \texttt{python3 analysis/run\_analysis.py}\\
$\to$ \texttt{analysis/output/results.json}, 논문 수치 매크로, 그림
\item 논문 빌드: \texttt{bash scripts/build\_paper.sh}
\item 실험 페이지 직접 실행: \texttt{cd web \&\& npm install \&\& npm run dev}
\end{enumerate}

\section{AI에게 맡긴 일과 직접 판단한 일}\label{app:ai}
이 연구는 AI(Claude)와 함께 진행했다.
역할 구분은 재현 패키지의 \texttt{docs/06-ai-and-me.md}에 기록했고, 요약은 다음과 같다.

\textbf{연구자가 판단한 일.} 여러 후보 가운데 직접 만든 웹 페이지로 행동 데이터를 모으는 ``시각 효과·경고 유무'' 실험을 주제로 골랐다.
실험을 4분짜리 한 세션이 아니라 짧은 미니게임 여러 개와 순위표가 있는 형식으로 바꾸게 했고, 대기 표시가 목표와 헷갈린다는 문제를 직접 찾았다.
AI가 거절한 중도 이탈률 수집을 다시 넣게 했다.
결과물을 공개 저장소에 남기기로 했고, 링크 공유와 수집을 운영했다.
AI 검토단의 지적을 받아들일지와 결과의 해석·결론은 연구자가 정했다.

\textbf{AI가 한 일.} 가설 문장의 결함 지적, 실험 페이지와 분석 코드 작성, 문헌 후보 제시, 원고 초안 작성을 맡았다.
문헌의 서지 확인도 AI가 웹 검색과 페이지 열람으로 두 차례 했다. 이 과정에서 원문 초록과 맞지 않는 연결 문장 1건을 찾아 고쳤다.
수집 전에는 원고 작성 과정을 보지 않은 AI 서브에이전트 4개(방법론·통계·반론·과제 기준)가 독립적으로 검토했고, 그 결과로 설계와 분석 계획을 한 차례 고쳤다.

\textbf{결과에 맞춰 고치지 않았다는 근거.} 분석 규칙과 해석의 두 갈래는 데이터를 보기 전에 공개 저장소에 커밋했다.
이후 바꾸면 그 이력이 커밋으로 남는다. 다만 이는 제3자 등록 기관의 사전 등록이 아니다.
